# 바꾸리 — 파일 변환을 간편하게

이미지와 문서를 원하는 형식으로 바꾸고, 여러 파일을 하나로 합치거나 용량을 줄이고, 파일 이름을 한꺼번에 바꾸는 Windows용 프로그램입니다.

[**1.0 베타 1 설치 파일 다운로드**](https://github.com/maneci20221213-coder/bakuri/releases/download/v1.0.0-beta.1/BakuriSetup.exe) · [일반 배포판](https://github.com/maneci20221213-coder/bakuri/releases/latest) · [파일 변환 설명](USER-GUIDE.md) · [파일명 변경 설명](RENAME-GUIDE.md)

현재 버전은 **1.0.0-beta.1**입니다. 베타는 직접 설치해 사용할 수 있으며 기존 일반판의 자동 업데이트로 배포하지 않습니다.

## 설치와 시작

1. **BakuriSetup.exe**를 내려받아 실행하고 **바탕화면에 바로가기 만들기**를 선택한 뒤 설치합니다. Windows 64비트 PC에서 사용할 수 있습니다.
2. 바꾸리가 이미 실행 중이면 작업 표시줄 오른쪽의 바꾸리 아이콘을 우클릭해 **완전 종료**한 뒤 설치합니다.
3. 실행 후 **파일 추가**를 누르거나 파일을 창으로 끌어 놓습니다.
4. 변환할 파일을 체크하고 **출력 형식**과 저장 방법을 고른 뒤 **변환 시작**을 누릅니다.

창 오른쪽 위의 **설정 옆 ? 버튼**이나 **F1**을 누르면 인터넷 없이 사용 설명을 볼 수 있습니다.

설치 파일에는 아직 디지털 서명이 없습니다. Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다. 이 저장소의 배포 파일인지 확인하고, 확인되지 않은 파일은 실행하지 마세요.

## 결과 파일은 어디에 저장되나요?

**원본 파일이 있는 폴더**에 새 파일로 저장합니다. 원본은 덮어쓰지 않습니다. 같은 이름이 있으면 숫자를 붙이고, 완료 후 **저장 폴더 열기**로 결과를 확인할 수 있습니다.

**선택 제거**는 바꾸리 목록에서만 파일을 빼는 기능이며, 내 PC의 원본 파일을 삭제하지 않습니다.

## 탐색기에서 바로 쓰기

파일을 선택하고 **백틱 키** (\`) 단축키를 누르거나, 우클릭 메뉴의 **바꾸리 파일 변환**을 선택하세요. Windows 11에서는 **더 많은 옵션 표시** 안에 있을 수 있습니다. 작은 메뉴에서 원하는 형식을 고르면 바로 변환됩니다.

- 단축키는 설정에서 F8·F9·Ctrl+Alt+B로 바꿀 수 있습니다.
- 여러 이미지를 PDF·한글로 바꾸거나 여러 PDF를 한글로 바꾸면, 작은 메뉴에서는 한 파일로 합칩니다.
- 따로 저장하거나 순서를 바꾸려면 **확장 기능**을 누르고 큰 창에서 진행하세요.

새로 설치하면 **윈도우 로그인 시 백그라운드 실행**이 기본으로 켜집니다. 원하지 않으면 설정에서 해제하세요. 기존 사용자의 자동 실행 설정은 유지합니다.

## 주요 기능

| 하고 싶은 작업 | 선택할 항목 |
| --- | --- |
| 이미지·문서를 PDF로 저장 | PDF |
| 문서의 각 페이지를 그림으로 저장 | PNG 또는 JPEG |
| 이미지·PDF·지원 문서를 한글 문서로 저장 | HWPX |
| 한글 문서를 Word 문서로 저장 | DOCX |
| 이미지·PDF를 슬라이드로 저장 | PPTX |
| 지원 표 문서를 Excel 문서로 저장 | XLSX |
| 이미지·PDF 파일 크기 줄이기 | 용량 축소 |

선택한 파일에 사용할 수 없는 출력 형식은 회색으로 표시됩니다. 여러 파일을 선택했다면 모든 파일에 사용할 수 있는 형식만 고를 수 있습니다.

한글 관련 문서 변환에는 **한글 프로그램**, Word·Excel·PowerPoint 문서 처리에는 **해당 Microsoft Office 프로그램**이 설치되어 있어야 합니다. PDF와 일반 이미지끼리의 변환에는 이 프로그램들이 필요하지 않습니다.

## 파일명 일괄 변경

파일을 추가하고 **파일명 변경** 탭을 선택하세요. 찾아 바꾸기, 문자열·연번 추가, 파일명 새로 쓰기를 적용할 수 있습니다. **파일별 문구**를 체크하면 나타나는 **추가할 문자열** 열과 **변경될 이름** 열을 한 번 클릭해 입력하거나, 엑셀 한 열·메모장의 여러 줄을 Ctrl+V로 붙여넣을 수 있습니다.

미리보기와 상태를 확인하고 **이름 변경 적용**을 누르면 실제 파일 이름이 바뀝니다. 확장자는 유지하며 같은 이름이 있으면 적용을 막습니다. 바로 옆 **실행 취소** 버튼으로 직전 변경을 복원할 수 있지만, 이후 파일이 수정·교체되거나 원래 이름을 다른 파일이 사용하면 되돌리기를 중단합니다.

완료 팝업과 트레이의 **최근 결과 보기**에서 결과를 확인할 수 있습니다. 자세한 내용은 [파일명 변경 설명](RENAME-GUIDE.md)에 있습니다.

## 한글 변환과 용량 축소 전에 알아두세요

- PDF·이미지를 한글이나 PowerPoint로 바꾸면 **페이지 그림**으로 들어갑니다. 글자를 따로 편집하는 문자인식 기능은 아닙니다.
- PDF→한글은 페이지마다 원래 크기와 방향을 유지하고, 용지 크기의 그림을 넣습니다. PDF 자체의 흰 여백은 유지합니다.
- 용량 축소 비율은 가로·세로 크기를 줄이는 비율입니다. 파일 용량이 같은 비율로 줄지는 않으며, 작은 글자가 흐려질 수 있습니다.
- 원본보다 작아진 경우에만 **_용량축소**라는 새 파일을 만듭니다. 일부 보호된 파일이나 이미 작은 파일은 건너뜁니다.
- 변환 후 중요한 내용과 인쇄 미리보기를 확인해 주세요. 복잡한 문서는 원래 모양과 다르게 보일 수 있습니다.

## 업데이트와 문제 해결

바꾸리 창을 직접 열면 새 버전을 확인합니다. **업데이트** 버튼을 눌러 동의한 뒤 다운로드·설치하며, **나중에** 또는 **이 버전 건너뛰기**를 선택할 수도 있습니다.

변환이 안 되면 원본이 정상적으로 열리는지 확인하고, 필요한 한글·Office 프로그램을 실행해 보세요. 여러 파일이라면 한 개씩 시도해 주세요. 단축키·우클릭 메뉴 문제와 그 밖의 해결 방법은 **? 버튼** 또는 [전체 사용 설명](USER-GUIDE.md)에 있습니다.

문제가 계속되면 바꾸리 버전, 원본·출력 형식, 화면의 안내 문구를 함께 알려 주세요. 개인 문서는 공개 게시판에 올리지 않는 편이 좋습니다.
