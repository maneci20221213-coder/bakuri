# 바꾸리 — 파일 변환을 간편하게

이미지·문서·CAD 도면을 변환하고, 파일을 합치거나 나누고, 용량과 파일 이름을 한꺼번에 정리하는 Windows용 프로그램입니다.

[**설치 파일 다운로드**](https://github.com/maneci20221213-coder/bakuri/releases/latest/download/BakuriSetup.exe) · [최신 버전과 변경 사항](https://github.com/maneci20221213-coder/bakuri/releases/latest)

## 설치와 시작
1. **BakuriSetup.exe**를 내려받아 설치합니다. Windows 64비트용이며, 바탕화면 바로가기 생성 여부를 고를 수 있습니다.
2. 기존 바꾸리가 실행 중이면 트레이 메뉴에서 **완전 종료**한 뒤 설치합니다.
3. 파일을 추가하고 출력 형식을 고른 뒤 **변환 시작**을 누릅니다. 사용할 수 없는 형식은 회색으로 표시됩니다.

기본 저장 위치는 원본 폴더이며, 설정에서 바꿀 수 있습니다. 원본은 덮어쓰지 않습니다. 설정 옆 **? 버튼** 또는 **F1**으로 사용 설명을 여세요.

## 탐색기에서 바로 변환
파일을 선택하고 **백틱(`)** 단축키를 누르거나 우클릭 메뉴의 **바꾸리 파일 변환**을 선택합니다. Windows 11에서는 **더 많은 옵션 표시** 안에 있을 수 있습니다.

- 설정의 **빠른 변환**에서 단축키와 파일 유형별 메뉴를 바꿀 수 있습니다.
- 여러 이미지 → PDF·한글, 여러 PDF → 한글은 한 파일로 합칩니다. 따로 저장하려면 **확장 기능**을 여세요.
- 작업 중 추가 요청은 대기열에 넣을 수 있습니다. 결과는 트레이 알림과 **최근 결과 보기**에서 확인합니다.

## 주요 기능
- PDF·PNG·JPEG·HWPX·DOCX·XLSX·PPTX 등 지원 형식으로 변환
- PDF·한글·Word 페이지 나누기와 원하는 페이지 추출
- 지원 파일 합치기, 이미지·PDF 용량 축소
- CAD(DWG·DXF)를 PDF·이미지로 변환
- 찾아 바꾸기, 문자열·연번 추가 등 파일명 일괄 변경과 직전 변경 실행 취소

[파일 형식 변환 사용법](USER-GUIDE.md) · [파일명 변경 사용법](RENAME-GUIDE.md)

## 사용 전 확인
- 한글 관련 변환에는 **한글**, Office 문서 처리에는 해당 **Microsoft Office**가 필요합니다.
- PDF·이미지를 한글·PowerPoint로 바꾸면 그림으로 들어갑니다. 글자를 직접 편집하는 기능은 아닙니다.
- 복잡한 문서와 도면은 원본과 다르게 보일 수 있으니 인쇄 전에 결과를 확인해 주세요.
- 설치 파일에는 아직 디지털 서명이 없습니다. 이 저장소에서 받은 파일인지 확인해 주세요. 설치 문제 안내는 [최신 배포 페이지](https://github.com/maneci20221213-coder/bakuri/releases/latest)에 있습니다.

## 업데이트와 문의
새 버전 안내에서 동의한 뒤 업데이트하거나 **이 버전 건너뛰기**를 선택할 수 있습니다. 다시 확인하려면 트레이 메뉴의 **업데이트 확인**을 누르세요. 문제가 계속되면 바꾸리 버전·입력/출력 형식·안내 문구를 함께 알려 주세요. 개인 문서는 공개 게시판에 올리지 마세요.
